## Хвосты

- Колонки источника в каталоге `/tags`. Сейчас там дерево в новом стиле, колонки есть в панели разметки.
- Строки плейлиста внутри медиатеки (`PlaylistLibrary.tsx`) перевести на новую строку.
- Массовая разметка: выбор голосов вместе с «С вокалом».
- Чанк `index` больше 500 кБ: разнести экраны по ленивым чанкам.
- Диск VPS: 85 % после чистки образов hibiki. Нужна регулярная очистка старых образов всех проектов (около 9 ГБ неиспользуемых).
- Поповер фасета слегка сдвигается при подстройке под содержимое (CLS 0,048).
- Кеш счётчиков по отдельным группам, если медиатека вырастет заметно больше 3000 записей.

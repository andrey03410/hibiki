# Продуктовые решения

Решения приняты агентом в автономном режиме по поручению владельца.
Дополнение владельца в ходе работы: «Бек и недостающую логику для сценариев
дизайна можно попутно допиливать».

## Цель

Интерфейс перестаёт выглядеть технично. Медиатека остаётся мощной, но показывает
меньше управления одновременно. Теги становятся навигацией, а разметка — быстрым
действием рядом со списком.

## Сценарии

1. Слушатель открывает медиатеку, выбирает вкладку «Игра», проваливается в
   «The Witcher 3» по хлебным крошкам и включает выдачу.
2. В разделе он открывает фасет «Жанр», видит счётчики внутри текущей выдачи и
   отмечает два жанра: выдача показывает записи с любым из них.
3. Он печатает в поиске «clann» и выбирает тег «ВН › CLANNAD» из подсказок —
   тег становится фильтром, текст поиска очищается.
4. Он открывает разметку записи, выбирает источник колонками, щёлкает
   настроения, видит «5/6» и тост «Отменить» после каждого изменения.
5. Он отмечает три записи и в поповере «Разметить» ставит «Celtic» всем:
   частичный тег становится полным, внизу видно число изменяемых записей.

## Решения

### P01. Навигация по тегам в медиатеке

- Варианты: оставить правую панель; заменить вкладками источника и фасетами.
- Рекомендация: вкладки корней источника, хлебные крошки с «внутри» и «рядом»,
  фасеты-поповеры для исполнителя, жанра, настроения и меток.
- **Решение:** правая панель удаляется. Поиск по всем тегам переезжает в
  подсказки строки поиска (⌘K / Ctrl+K фокусирует её).

### P02. Логика нескольких тегов

- Варианты: глобальный И/ИЛИ (как сейчас); И между группами, ИЛИ внутри группы.
- Рекомендация: второй вариант по умолчанию, как в каталогах магазинов. В
  поповере группы — переключатель «Любой из / Все».
- **Решение:** принято. Строка активных фильтров показывает «И» между группами.
  MCP сохраняет прежние `tagIds`/`tagMode`.

### P03. Счётчики фасетов

- Варианты: как сейчас (без учёта выбранных тегов); с учётом выбранных тегов других групп.
- Рекомендация: учитывать теги других групп, а для своей группы — не учитывать её
  же выбор (классический фасетный поиск). Нули в поповере уходят вниз и тускнеют.
- **Решение:** принято при условии замера стоимости запроса (см. T02).

### P04. Меню разметки записи

- Варианты: улучшить модалку; боковая панель.
- Рекомендация: боковая панель с вкладками «Разметка / Название и заметка /
  Источники / Видеоряд / История», колонками источника, кнопками настроений и
  меток, поиском исполнителей и жанров, кольцом заполненности и автосохранением.
- **Решение:** принято. Кнопки «Сохранить» и «Завершить разметку» удаляются:
  изменения сохраняются через 450 мс после последнего действия, тост даёт
  отменить последнее изменение. Навигация «Пред./След.» идёт по текущей выдаче.

### P05. Массовая разметка

- **Решение:** поповер с чипами в трёх состояниях (нет / у части / у всех) для
  всех групп и исполнения. Клик по частичному — у всех, повторный — снять.
  Применение через существующий пакет с проверкой ревизии.

### P06. Вид «Обзор»

- **Решение:** третий вид медиатеки показывает дочерние разделы текущего узла
  источника плитками со счётчиком. Обложки плиток генеративные (градиент и
  монограмма) как запасной вариант; настоящая обложка раздела берётся из
  лёгкого серверного запроса (одна запись с обложкой на раздел), если замер
  подтвердит дешевизну.

### P07. Строка трека

- **Решение:** колонки «обложка / название и версия / исполнитель / путь
  источника / два тега / длительность / действия». Тип записи и значки
  источника уходят в подсказку и детали. Недостающая разметка — значок ✦.

### P08. Меню сайта

- **Решение:** «Медиатека, Плейлисты, Теги, Задания»; «Плеер» открывается из
  дока, «Мои ссылки» переезжают в «Настройки» (старый адрес остаётся).
  В списке плейлистов вместо точек — маленькие обложки.

### P09. Плеер, плейлисты, задания, настройки

- **Решение:** UX плеера и плейлистов сохраняется; новый вид: фон из цвета
  обложки, плавающий док мини-плеера, шапка плейлиста в цветах обложки.
  Задания группируются «Сейчас / Ранее». Настройки — подразделы слева.

### P10. Цвет

- **Решение:** у групп постоянные цвета; у настроений свои оттенки (по названию,
  с запасной палитрой). Если пользователь сам задал цвет тегу, он важнее.
  Акцент текущего трека берётся из его обложки.

## Критерии провала

- Любая функция старого интерфейса недоступна в новом.
- Скачки макета при загрузке выдачи, счётчиков или обложек.
- Рост времени ответа `/library/page` без выбранных тегов.

## Не входит

- Светлая тема, отдельный мобильный макет.
- Полоса «Продолжить» в плейлистах (нужна позиция внутри плейлиста из истории).
- Конструктор правил «фразой» вместо дерева правил: в этой задаче редактор правил
  получает новый вид, структура остаётся.

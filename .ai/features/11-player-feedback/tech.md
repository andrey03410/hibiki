# Технические решения

- P01. Медиатека передаёт уже доступную страницу в существующий PlayerProvider. Отложенный ответ полного порядка привязан к выбранной очереди. Навигация через границу страницы ожидает данные, ошибки допускают повтор. Выбранный источник и идентичность попытки сохраняются.
- P02–P03. Общий разбор команд использует физические клавиши с учётом фокуса и модификаторов. Жест на локальном видео различает одиночный и двойной щелчок. Одна полноэкранная сессия управляет таймером независимо от источника.
- P04–P05. Для текущего источника различаем намерение запустить и события реального воспроизведения. Общий регулятор связан с сохранёнными настройками. Визуальная шкала локально читает часы медиа, учитывает буфер и пользовательскую перемотку. История использует исходные события.
- P06. Карточки читают общие метаданные и подготовленные счётчики владельца. Обновление счётчиков выполняется вне запроса каталога с учётом изменений правил, медиатеки и истории. Лишь явный запуск запрашивает состав выбранной подборки. Формат объяснений полного состава для страницы плейлиста и MCP сохраняется.

# Технические решения

- T01. В Workspace запрос полного снимка выполнялся при входе и каждые три секунды. Для медиатеки вводим отдельную сводку и серверный запрос страниц. Старый контракт снимка сохраняется для существующих клиентов. Сервер применяет фильтры владельца до выдачи, с детерминированным порядком при одинаковых значениях.
- T02. Страницы добавляет IntersectionObserver. При смене запроса клиент отбрасывает запоздавшие ответы. Отдельные действия над всей выборкой используют её идентификаторы. Данные очереди и редакторов загружаются по потребности. Фоновое обновление сводки не сбрасывает прокрутку при неизменном каталоге.
- T03. Маленькая обложка использует отдельный размер, ограниченную обработку и кэш. Доступ к локальным обложкам проверяет сервер. Изображения в списке загружаются лениво и декодируются асинхронно.
- T04. Точки запуска библиотеки задают аудиорежим. В нижнем плеере отдельно проверяется наличие воспроизводимого видеоряда. Меню тегов располагается поверх карточки и доступно с клавиатуры.

Затронутые зоны — [медиатека](../../map/media.md) и [веб-плеер](../../map/web.md). Проверяем API двух владельцев, выдачу в реальном браузере, размеры изображения, декодирование медиа и выпуск через Production.

# Техника доступа по ссылке

- **T01. Выдача и отзыв.** SQLite хранит отдельные ссылки с непрозрачным случайным токеном, владельцем, объектом, сроком и состоянием отзыва. Превью и выдача медиа требуют активного аккаунта. Провайдер доступа сначала проверяет срок, отзыв и существование оригинала, затем разрешает только записи исходного плейлиста. Сайт и MCP используют один сервис. Управление ссылкой требует владения.
- **T02. Состав.** Когда опубликованная фоновым расчётом версия актуальна, читаем её ID и порядок. Для свежих правок используем текущую логику разрешения плейлистов и переиспользуем результат до смены версии либо ближайшей границы правил по истории. Данные состава общие для всех ссылок и сохранений. Попап читает готовый счётчик, выдача и смена срока обходятся без полного расчёта.
- **T03. Сохранение.** Получатель сохраняет ссылку на исходный плейлист или свою запись с привязками к одной или нескольким ссылкам. Чужие файлы не прикрепляются к его данным. Источники для воспроизведения вычисляются из действующих привязок. Теги и история получателя хранятся на его записи. В экспорт попадают только его метаданные и собственные источники.
- **T04. Поток.** Локальные файлы и обложки выдаются отдельными маршрутами с проверкой доступа на каждый запрос. Маршруты владельца продолжают проверять владение. Поток поддерживает Range и закрыт от долгоживущего клиентского кэша. Для YouTube используются существующие возможности внешнего провайдера.
- **T05. Копирование.** Явное действие запускает фоновое задание. Оно повторно проверяет действующий доступ перед чтением источника и публикацией результата. Локальный файл поступает в существующий импорт, а YouTube использует штатное скачивание и ограничения. Импорт сохраняет собственный источник получателя и переиспользует файл с тем же хэшем.
- **T06. Интерфейс.** Ссылка ведёт на `/share/:token`, вход через Kaname возвращает на этот путь после проверки допустимого маршрута. «Мои ссылки» доступны из основной навигации. Воспроизведение вызывает текущий плеер. Выдача общих данных скрывает правила, заметки и остальные личные поля автора.

Решения приняты агентом в подтверждённом автономном режиме. Карта после реализации отражает изменения медиа, плейлистов, сайта, MCP, заданий и переноса.

# 13. Записи и плейлисты по ссылке

Пользователь делится записью или плейлистом с другими пользователями Hibiki. Получатель может открыть ссылку, воспроизвести медиа и сохранить доступ в своей медиатеке.

Владелец подтвердил продукт и разрешил автономную реализацию, приёмку, вливание и проверку продового деплоя.

# 14. Личная выдача медиатеки и загрузка треков

Три способа упорядочить медиатеку, достоверная полоса загрузки, догрузка текущего трека, предзагрузка следующего и скорость поиска. Владелец запросил самостоятельные предложения по всем семи пунктам для последующего обсуждения.

Владелец 24 ноября разрешил автономную реализацию всех семи пунктов, живую проверку, замеры, вливание и деплой.

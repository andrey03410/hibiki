# Техника

T01. Флаг KANAME_ENABLED=1 включает проверку назначения из Kaname на сервере. Authorization Code Flow проверяет PKCE, state, подпись ID token, issuer, audience и nonce. Одноразовое состояние привязано к HttpOnly-cookie. Локальные сессии помечаются способом входа.

T02. Аддитивная SQLite-миграция связывает User.id с issuer/subject и хранит локальную приостановку и суточную активность. Учётные данные портала и службы отчётов разделены. Сервер и worker проверяют центральные права. Запись медиа ограничивается общей квотой в SQLite при конкурентной обработке.

T03. Обновляются карты медиа, MCP, заданий и архитектуры. Проверки выполняются в отдельном SQLite-хранилище, затем на живом HTTP и в браузере. Промышленная привязка, контрольное восстановление и проверка SHA выполняются при координированной выкладке.

# Технические решения

T01. На каждой ShareLink хранится allowReshare с начальным значением false. Миграция аддитивная. На сайте и через MCP владелец может поменять разрешение у действующей ссылки без замены адреса. Изменение срока и разрешения поддерживает частичное обновление.

T02. Права на полученную позицию зависят от текущего состава обоих плейлистов, состояния авторов и действующих ссылок. Сервер проверяет ровно один исходный переход и умеет выбирать из нескольких сохранённых разрешений. Страница, медиа и обложки используют одно правило. Самостоятельный источник составителя имеет приоритет. Для отдельного сохранения требуется прямое право. Сетевые проверки аккаунтов выполняются вне транзакции SQLite.

T03. Для совместимости items содержит доступные записи, trackCount — их число. positions задаёт порядок по ID доступных записей и null на закрытых местах; totalCount учитывает все позиции. Делегированная запись использует ID позиции составителя. Сведения об исходной ссылке скрыты. Очередь использует только доступные записи. Владелец получает числа позиций без разрешения и с недоступным оригиналом. У обычной подборки остаётся быстрый путь к готовому счётчику.

T04. Проверяем сайт, живой MCP, медиа, миграцию и серверную выдачу на трёх аккаунтах. Продовые ссылки пользователей не меняем. Карточки знаний — плейлисты, сайт, MCP и медиа.

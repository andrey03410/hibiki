# Продуктовая постановка

- P01. При входе из медиатеки карточки показывают счётчики и доступные обложки. Для пустых подборок и отсутствующих изображений отображается текущая заставка. Решение в автономном режиме — сначала загружать обложки рядом с видимой областью.
- P02. Щелчок по обложке запускает плейлист в его актуальном порядке. На время ожидания виден индикатор. Из двух быстрых щелчков по разным карточкам побеждает последний. Решение в автономном режиме — запускать плеер с компактным ответом и загружать остальные сведения о записях после старта.
- P03. Сохраняются переход по названию, перемешивание, правила, недоступные источники и привязка попыток в истории. Приёмка включает пустой, обычный и большой плейлисты, обновление состава и реальное воспроизведение после выкладки.

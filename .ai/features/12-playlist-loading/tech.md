# Технические решения

Каталог после PR №12 использует готовые счётчики. Изображения исчезли из-за вызова `Cover` без сведений об источниках. Запуск ждал `/resolve`, который считывает полную медиатеку и возвращает объяснения и все DTO результата. В Chrome на проде ответ для 203 записей занял 2,84 с и передал 398 КБ до запроса медиа.

- T01. Публиковать небольшой список кандидатов для обложки в той же фоновой операции, что счётчики. Брать компактные миниатюры YouTube и разрешённые локальные обложки. Пробовать до трёх кандидатов, загружая по одному рядом с видимой областью.
- T02. Материализовать упорядоченные ID вместе со счётчиком. Браузерный вызов старта проверяет версию расчёта и ближайший порог истории, а затем возвращает полный порядок и DTO только первой порции. Пока снимок отсутствует или устарел, тот же движок вычисляет порядок по минимальной проекции текущей библиотеки.
- T03. Для очереди использовать существующий каталог DTO и правила выбора источника. Сохранить порядок, перемешивание, атрибуцию истории и обработку недоступных записей. Подробный состав и MCP используют существующий API.

На этапе реализации владелец разрешил полностью переработать теги аккаунта. При переносе сверяются отображаемое и исходное названия каждой композиции. Нижняя панель воспроизведения вынесена за границы фичи. Для сочетания старых тегов OST и vocals согласовано предложение «С вокалом» в предпросмотре. Голоса владелец укажет при разметке.

## Проверка дизайна

В Chrome проверены 24 демонстрационные композиции при 1440 × 920 и 900 × 650. Проверка охватывает закрепление панели над мини-плеером при прокрутке, поиск внутри раздела, оба написания Kyoto Animation, одноимённые произведения, фильтр исполнения наверху, общие И/ИЛИ, поиск каверов и ремиксов в «Дополнительно», список и карточки. Пример K-ON! с настроением «Быстрая» даёт две записи для И и семь для ИЛИ. Проверены три соседние отметки, снятие четвёртого тега через «Ещё 1» и регулировка ширины мышью и клавиатурой с восстановлением после перезагрузки. Кнопка подробностей открывается с клавиатуры, Escape возвращает на неё фокус. Раскрытие ветки использует переход 155 мс, при уменьшенном движении анимация отключается.

Скриншоты, воспроизводимая проверка прототипа и результаты изучения коллекции лежат локально в `storage/verification/09-library-tag-navigation/`.

Владелец разрешил переназначать черновые теги аккаунта на этапе реализации. Для сочетания старых тегов OST и vocals согласовано предложение «С вокалом» в предпросмотре. Голоса владелец укажет при разметке.

## Проверка дизайна

В Chrome проверены 24 демонстрационные композиции при 1440 × 920 и 900 × 650. Проверка охватывает закрепление панели над мини-плеером при прокрутке, поиск внутри раздела, оба написания Kyoto Animation, одноимённые произведения, выбор нескольких голосов, режимы «Любое / Все», быстрые фильтры, список и карточки. Кнопка подробностей открывается с клавиатуры, Escape возвращает на неё фокус. Раскрытие ветки использует переход 155 мс, при уменьшенном движении анимация отключается.

Скриншоты, воспроизводимая проверка прототипа и результаты изучения коллекции лежат локально в `storage/verification/09-library-tag-navigation/`.

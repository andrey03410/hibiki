# Технические решения

Сайт, Fastify и MCP делят LibraryService и схемы contracts. SQLite хранит старую уникальную идентичность Tag.name в пределах владельца. Новое отображаемое имя label позволяет различить одноимённые узлы. У тега группа source / artist / genre / mood / extra, списки aliases и parentIds, признак archived. У записи performance (unknown / ost / vocal) и voices (male / female). Значения списков в SQLite хранятся как JSON, в DTO — массивы. Для старых DTO предусмотрены значения по умолчанию. Служебные архивные связи доступны старым правилам и синхронизации, текущий каталог показывает активные.

Сервер выдаёт общую выборку по предкам, И/ИЛИ и исполнению. Поиск исполнителей плоский. tagMode и performanceFilter входят в идентичность курсора. Запросы проверки неполной разметки учитывают все обязательные роли. Редактирование групп и связей проверяет владение и циклы. Перенос archive remap затрагивает родителей и выступление. Новые возможности доступны внешнему агенту в рамках существующей модели доступа.

Для переноса коллекции использовать отдельный проверяемый пакет с ревизией библиотеки. Снимок до изменения, атомарное применение и проверка названий, избранного, плейлистов, числа записей и покрытий. Артефакты аккаунта находятся вне Git. Переработка данных происходит отдельно от выкладки приложения.

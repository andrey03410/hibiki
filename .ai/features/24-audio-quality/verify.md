## Ревью

Свежий ревьюер (отдельный агент, только чтение диффа `main...codex/24-audio-quality`).

- **Копия навсегда «без потерь», если оригинал не измерился** (таймаут, нет файла) → исправлено:
  копия ждёт измерения оригинала и остаётся кандидатом; тест «keeps a prepared copy unmeasured…».
- **Ревизия медиатеки меняется на каждый файл во время анализа** → результаты пачки (до 64 файлов)
  пишутся одной транзакцией, открытая выдача видит одно изменение на пачку.
- `pcm_mulaw`/`pcm_alaw` считались без потерь → теперь с потерями; тест.
- Общий битрейт контейнера подставлялся при обложке или нескольких дорожках → только когда в файле
  единственный поток; тест.
- Проба хранимых файлов без списка разрешённых контейнеров → `inspectQuality` использует его.
- Лог worker каждые 10 минут из-за отсутствующих файлов → пишет только при обновлениях.
- Снятие одного кодека выбранного класса теряло кодеки вне текущей выдачи → учитываются кодеки
  всей медиатеки (`overview.audioCounts`).
- Оставлено: качество источников целиком в ответе карточек (300–500 Б на локальный источник;
  нужно карточке записи, ответ сжимается); теоретическое расхождение порядка `rowid` в SQL и порядка
  Prisma без `orderBy` при двух доступных локальных источниках без предпочтения; DTS-HD MA считается
  с потерями (нет в медиатеках).

## Ограничения

- Мобильная ширина: колонка названия в списке сжата кнопками строки (100 px) — так было до задачи,
  колонка качества на узком экране скрыта. Записано в «Хвосты».
- Пока worker анализирует прежние файлы, триггер `MediaFile` увеличивает ревизию медиатеки на каждый
  файл: открытая выдача может перезагрузиться, счётчики плейлистов пересчитываются. На проде это
  несколько минут один раз после выкладки; так же работало дозаполнение `hasAudio`.
- Эвристика связи прежних копий: копия и оригинал `unsupported_codec` одной записи, созданные в пределах
  10 минут. Новые импорты пишут связь явно.
- Звук с потерями сортируется только по битрейту, без поправки на эффективность кодека (P05).

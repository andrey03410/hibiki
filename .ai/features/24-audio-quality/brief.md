## Трек

`product` — меняются UI медиатеки, карточка записи и ответы MCP.

## Успех

- У каждой записи с локальным файлом в выдаче виден значок качества: «FLAC 24/96», «AAC 128», «MP3 320».
- В карточке записи для каждого источника видны контейнер, кодек, профиль, битрейт, частота,
  разрядность (для без потерь), каналы, а для видео — кодек, разрешение, fps и битрейт.
- Фасет «Качество» фильтрует по классу и кодеку, сортировка «Качество звука» работает.
- MCP `media_list`/`media_get` возвращают те же метаданные, фильтр и сортировку.
- После деплоя все существующие файлы всех аккаунтов на проде проанализированы автоматически.

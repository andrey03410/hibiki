# План

**Цель:** сохранить качество каждого медиафайла и показать его на сайте и в MCP,
с фильтром, сортировкой и фоновым анализом существующих файлов.

**Подход:** разбор stderr FFmpeg в чистой функции, колонки `MediaFile`, общий выбор
файла записи в JS и SQL, затем контракты, MCP и интерфейс.

## Задачи

- [ ] **1. Разбор качества.** Файлы: `apps/server/src/media-quality.ts`, `media.ts`,
  `packages/contracts/src/index.ts`. Тесты: `media-quality.test.ts` на настоящих файлах из
  FFmpeg (FLAC 24/96, FLAC 16, PCM WAV, ADPCM WAV, ALAC, MP3, AAC, Opus, Vorbis, MP4 H.264) и
  строках продового FFmpeg 7. Готово, когда подписи и классы совпадают с P01/P02.
- [ ] **2. Хранение и импорт.** Миграция `MediaFile`, запись при импорте и связь копии.
  Тест: импорт ADPCM WAV даёт копию с `originFileId` и классом «с потерями».
- [ ] **3. Дозаполнение.** `backfillQuality`, связь прежних копий, worker при старте и раз в
  10 минут, `--backfill-quality`. Тест: старые файлы получают качество, повторный запуск
  ничего не делает, отсутствующий файл пропускается.
- [ ] **4. DTO, фильтр, сортировка, числа.** `itemDto`, `itemWindow`, `sharing.ts`,
  `library-pages.ts`. Тесты: фильтр по классу/формату/паре, сортировка в обе стороны,
  курсор MCP, `audioCounts`.
- [ ] **5. MCP.** `view=summary`, описания, `capabilities`. Тест через MCP-клиент в тестах.
- [ ] **6. Сайт.** Значок в строке и карточке выдачи, фасет «Качество», сортировки, чип
  активного фильтра, вкладка «Источники». Тесты моделей поиска.
- [ ] **7. Знания.** Карточки media, web, mcp, jobs, дизайн-система; строка в AGENTS.md.

## Живые проверки

- Локально: `npm run dev`, загрузка тестовых файлов разных кодеков, браузер — значки,
  фасет, сортировка, карточка; MCP-клиент — `media_list`/`media_get`.
- Worker: миграция на копии продовой БД (только локально), дозаполнение и повтор.
- Прод: деплой, журнал worker, `qualityVersion` всех файлов всех аккаунтов, страница медиатеки.

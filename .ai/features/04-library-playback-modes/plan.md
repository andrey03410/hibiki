# План реализации медиатеки и режимов воспроизведения

> Для пошаговой реализации — superpowers:subagent-driven-development или superpowers:executing-plans.

**Цель.** Рабочая медиатека без видео, отдельный экран плеера, звуковой режим,
очередь из выдачи, быстрые фильтры и компактные карточки.

**Архитектура.** Один `PlayerProvider` управляет очередью и выбирает источники.
Поиск и отбор записей остаются общими для двух представлений. Сервер добавляет
сведения о звуковой дорожке уже проверяемых файлов.

**Стек.** TypeScript, React Router, Fastify, SQLite/Prisma, Vitest, FFmpeg.
**Спецификация.** [Продукт](product.md) и [технические решения](tech.md).

## Границы и точки ревью

- Видео на экране «Плеер». Автопереход к видео за пределами этого экрана ждёт
  «Смотреть». Живой тест подтверждает отсутствие проигрывания до действия.
- Переключение между режимами в середине записи сохраняет очередь и позицию.
- Видео без звука и YouTube без копии остаются в очереди с понятным состоянием.
- Старые локальные файлы, настройки и архивы продолжают работать.
- Переупорядочивание поиска и смена представления не изменяют уже запущенную очередь.

# Проверка

19 ноября 2026 года. Проверка проведена на отдельной SQLite-БД с сервером и
worker Hibiki. Для браузерных сценариев использованы два проверочных аккаунта.

## Автоматические проверки

1. `npm test` — 246 тестов, 22 файла, все прошли.
2. `npm run build` — сборка прошла. Vite сообщает о размере основного JS
   (536,85 кБ, gzip 158,58 кБ).
3. `npx tsc --noEmit` — без ошибок.
4. `git diff --check` — без ошибок.

Целевые тесты дополнительно покрывают MP4 со звуком и без него, обновление
метаданных старого файла, импорт ZIP и перенос режима, совместимость подписи
старого локального снимка, фильтры и работу запроса без тела.

## Независимое ревью

Два независимых прохода по плееру и серверным данным. Исправлены гонка
открытия маршрута при первом запуске, потеря позиции до загрузки метаданных,
возобновление из активной строки плейлиста, подпись старого локального снимка,
использование устаревших метаданных из плейлиста и переход в «Плеер» при
доступности одной аудиокопии видеозаписи. Исправления проверены целевыми
тестами и живыми сценариями переходов.

Попутно исправлен выход из аккаунта: Fastify отвергал пустой POST с заголовком
JSON. Браузерный повтор подтвердил выход и повторный вход.

## Что посмотреть руками

1. В медиатеке выбрать сортировку, запустить аудио из смешанной выдачи и
   дождаться следующего ролика. «Смотреть» появится в нижней панели.
2. Включить локальное видео, перейти в медиатеку и обратно через «Смотреть».
   В плеере переключить «Только звук».
3. Переключить список на карточки, добавить два тега, свернуть дополнительные
   фильтры и снять одно условие с выдачи.

# 16. Производительность прослушивания и основных сценариев

Аудит охватил 18 проблем воспроизведения и медиатеки. По дополнительному
поручению владельца измерены загрузка оригинального видео и работа MCP.
Через MCP можно заменить источник у существующей карточки.
[Решения аудита](summary.md) · [Замеры до и после](verify.md)

Владелец разрешил проверять сценарии на своём прод-аккаунте и создавать временные
сущности с обязательной очисткой. Треки менять, сжимать и перекачивать нельзя.
Звук видео извлекается на лету, без копии на диске.

25 ноября владелец разрешил полную реализацию и выкладку: «Действуй автономно вплоть до деплоя».

Первая реализация вышла в [PR №18](https://github.com/andrey03410/hibiki/pull/18).
Во [второй итерации](https://github.com/andrey03410/hibiki/pull/22) учтены замеры
на рабочем аккаунте и стабильность MCP при выкладке. Упреждающая загрузка
оригинала в видеорежиме вышла в [PR №24](https://github.com/andrey03410/hibiki/pull/24).
По результатам проверки изменены холодный старт видеоплеера и восстановление
воспроизведения в WebKit. [PR №26](https://github.com/andrey03410/hibiki/pull/26)

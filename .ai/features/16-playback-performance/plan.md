# План

**Цель.** Устранить проблемы П1–П18 из [product.md](product.md) и достичь целевых
показателей. Направления решений — T01–T17 в [tech.md](tech.md).

**Подход.**
- Сначала снимается повторяемый замер «до».
- Работы идут этапами: быстрые правки, доставка звука, виртуальный звук видео,
  каталог и обложки, качество новых файлов.
- Новое поведение вводится через тест с наблюдаемым красным результатом.
- После каждого этапа — тройка `npm test` → `npm run build` → `npx tsc --noEmit`
  и замер T17. Этап не считается готовым без цифр «после».

Старт реализации — по сигналу владельца «реализация».

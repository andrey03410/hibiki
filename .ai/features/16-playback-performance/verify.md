## Проверки реализации

- Перед работами сверены содержимое 2 970 файлов с SHA-256 и контрольные суммы
  карточек, правил плейлистов, связей тегов, настроек и истории.
- Живой клиент MCP в изолированной установке получил импортированную карточку.
  Второй аккаунт прочитал Range общей виртуальной дорожки до отзыва ссылки.
  При повторном обращении после отзыва сервер вернул 404.
- При полном ZIP-переносе в другой аккаунт совпали хеш оригинала, хеш виртуальной
  дорожки и порядок записей в плейлисте. В архив вошёл один исходный медиафайл.
- В локальных Chrome и WebKit проверены декодирование, перемотка, офлайн-буфер,
  граница предзагрузки, прокрутка очереди из 2 668 записей, обрыв JSON во время
  воспроизведения и редактирование плейлиста.
- В пробной загрузке YouTube звуковые пакеты исходного WebM, полученного Ogg
  и дорожки видеоверсии MP4 дали одинаковый SHA-256.

и пять подключений. Для всех 46 операций медиана составила 142 мс, p95 — 211 мс.

повторное обращение к MCP вернуло HTTP 401.

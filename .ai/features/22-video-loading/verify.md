## Ревью

Отдельный ревьюер прочитал дифф `301e7f0..HEAD`. Все замечания исправлены.

- Сбой видео менял зависимость слушателя ретранслятора и обрывал чтение звука → видео-токен убран из зависимостей.
- Отозванное общее видео продолжало играть из памяти → проверка доступа HEAD раз в 10 с при каждом чтении декодера и сдвиге позиции. Таймаут и 5xx не останавливают видео, останавливает только отказ.
- Чтение декодера в видеорежиме тянуло весь файл без темпа → чтение ограничено окном, дальше видео загружает только догрузка с подсказкой скорости. Тест падает на прежнем коде.
- Переход ClipVideo на прямой адрес не останавливал загрузку во вкладке → плеер переключает токен и очищает загрузчик.
- Окно не двигалось при непрерывном воспроизведении → позиция сравнивается с последним решением. Тест падает на прежнем коде.
- Для повторяющегося клипа `#t=` получал время песни → у клипа фрагмент не ставится.
- Три попытки на всю догрузку → счётчик сбрасывается после прогресса. Покрытие пересчитывается раз в 500 мс. Подготовленная следующая запись при выборе прерывает фоновый запрос и продолжает с обычным приоритетом.

## Что посмотреть руками

- [ ] Включить звук записи с видео из медиатеки, навести курсор на «Открыть видео» и нажать. Видео появляется сразу, звук не прерывается.
- [ ] Нажать «Открыть видео» сразу, без наведения. Звук не прерывается, обложка сменяется видео без надписи «Загружаем видеоряд…».
- [ ] В видеорежиме полоса загрузки растёт до конца. Перемотка в заполненную часть сразу показывает кадр.
- [ ] Перемотка дальше заполненной части: звук продолжается, остаётся последний кадр, затем видео догоняет.
- [ ] Вернуться в медиатеку: звук продолжается, загрузка видео прекращается.
- [ ] Для замеров в своём Chrome: `localStorage.hibikiPlaybackDebug = "1"`, перезагрузить страницу, затем `hibikiPlayback()` в консоли.

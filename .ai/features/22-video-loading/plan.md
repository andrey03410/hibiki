# План

1. **Индекс и окно по времени** — `apps/web/src/video-index.ts`.
   Таблицы сэмплов из `moov` через mp4box, окно `[t − 10, t + 10]` в байтах от ключевого
   кадра, перевод загруженных байтов во время. Юниты на синтетических таблицах.
   Готово: тесты на окно, длинный интервал между ключевыми кадрами и покрытие.
2. **Загрузчик видео во вкладке** — `apps/web/src/video-delivery.ts`.
   Страницы 64 КиБ, индекс, окно, запрос декодера, догрузка до конца с подсказкой скорости,
   следующая запись, бюджет 256 МиБ, повторная проверка доступа по ссылке.
   Ответы для ретранслятора. Юниты с поддельным сервером.
   Готово: порядок запросов соответствует T02, при выходе из видео загрузка останавливается.
3. **Ретранслятор** — `audio-relay.ts`: один слушатель отдаёт диапазоны звука и видео по токену.
4. **Плеер** — `player.tsx`: индекс в звуковом режиме, окно по намерению (наведение и фокус
   на «Открыть видео»), видеорежим с догрузкой после звука, подготовка следующей записи,
   полоса загрузки как пересечение звука и видео.
5. **ClipVideo** — звук не ждёт картинку, кадр не скрывается при перемотке, обложка до
   первого кадра, надпись только после 1,5 с без кадра, запасной прямой адрес при сбое.
6. **Замеры** — `playback-debug.ts`: метки и сводка в консоли по
   `localStorage.hibikiPlaybackDebug`.
7. **QG** — тройка, локальная живая проверка, свежее ревью, verify.md.
8. **PR, вливание, деплой и замеры на проде** — те же сценарии, что в аудите.
9. **Знания** — `.ai/map/web.md`, CLAUDE.md, история.

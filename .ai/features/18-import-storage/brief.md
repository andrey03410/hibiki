## Объём и критерий успеха

Продуктовый трек. Для каждой открытой и закрытой issue сверить исходный пользовательский сценарий с текущей основной веткой Hibiki. Для актуальной проблемы предложить поведение и проверяемые признаки успеха. Для решённой показать, как воспользоваться решением и чем подтверждён результат.

Текущее поручение заканчивается черновиком продуктовой спецификации для вычитки. Решения по новым возможностям принимает владелец после чтения.

# 18. Освобождение места после импорта медиатеки

Hibiki освобождает исходный ZIP после применения импорта, учитывает одновременные записи в квоте и даёт владельцу очистить старые архивы с сайта или через MCP. [Постановка и результаты сверки issues](product.md) · [Приёмка](verify.md).

## Автономная реализация

> Переходи к автономной реализации вплоть до деплоя. Главное чтобы квота соответствовала фактическому занимаемому месту на диске, то есть после удаления промежуточноого архива места освобождается, но больше квоты занять юзер все равно не может. Также через mcp нужно поддержать возможность чистки своего пространства.

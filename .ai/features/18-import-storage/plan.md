# План

1. Жизненный цикл ZIP. В JobsService и модуле хранения реализовать просмотр доступной очистки, безопасное удаление по владельцу, согласование с повтором и worker. Доказать на реальном ZIP, в том числе для старых jobs.
2. Учёт места. Проверить пути uploads, importLocal, inspection и applyArchive, временные файлы, переиспользование существующих файлов и метрики Kaname. Закрепить предельные случаи тестами с конечной квотой.
3. Интерфейс. В настройках дать разбивку объёма, оценку очистки, подтверждение и результат, в заданиях отображать состояние архива. Проверить в браузере.
4. HTTP и MCP. Подключить к одному сервису оценку и очистку своего пространства. Проверить отказ без подтверждения и чужие данные, затем выполнить проверку через официальный клиент.
5. Обновить карточки зон, пройти тесты, сборку, типы и ревью. Открыть PR, дождаться CI, влить и проверить production и worker. Закрыть обе issues со ссылками на изменения и проверку.

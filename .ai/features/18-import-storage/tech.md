# Технические решения

- T01. Сервер связывает опубликованный архив с предпросмотром и заданиями применения. После фиксации успеха можно очистить архив. Состояние должно переживать перезапуск. Операции создания повторного задания и очистки сериализуются для одного архива. Старые успешно применённые архивы доступны для добровольной очистки.
- T02. Каждый одновременно записываемый пользовательский файл оплачен местом до записи. Переход между временным файлом и постоянным либо переносит файл без второй копии, либо резервирует обе копии. Списание за ZIP снимается после удаления. Квота измеряется байтами содержимого файлов. Общие SQLite, служебные логи и системные кеши сервера принадлежат установке.
- T03. Одна серверная реализация для REST, MCP и автоматического освобождения. Право определяется текущей сессией. Клиенту выдаются агрегаты в байтах без путей и содержимого личных архивов. Явное подтверждение нужно для массового удаления старых архивов.
- T04. Проверки охватывают две учётные записи, совместное использование ZIP, прерывание, израсходованную квоту, сравнение размера файлов со счётчиком, интерфейс и реальный транспорт MCP.

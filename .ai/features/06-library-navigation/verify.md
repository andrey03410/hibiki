# Проверка навигации и воспроизведения

## Автоматические проверки

- `npm test` — 261 тест в 24 файлах.
- `npm run build` — успешно. Сохраняется предупреждение Vite о бандле больше 500 КБ.
- `npx tsc --noEmit` и `git diff --check` — успешно.
- Целевые тесты проверяют подсчёт и порядок тегов, раскрытие тегов записи,
  выбор действия для текущей записи и состояния строк очереди.

## Встроенный браузер

Проверка прошла на отдельной тестовой базе с 21 записью и 27 тегами. Для MP3 и
MP4 проверялись реальное состояние и позиция браузерных аудио- и видеоэлементов.

| Сценарий | Наблюдение |
|---|---|
| Поиск и теги | «Все теги» показало 27 вариантов. Выбор Key и Фортепиано вместе с запросом Signal оставил одну запись. Тег из каталога и тег в плейлисте открыли нужную выдачу. |
| Все теги записи | Раскрытие «+5» показало все семь тегов в списке. В карточках раскрытие сработало с клавиатуры. |
| Плотность интерфейса | На 320, 375, 837 и 1440 px обложка, обе команды видео, избранное и меню не пересекались. Горизонтальной прокрутки списка не было. Карточки и каталог тегов поместились на 375 px. |
| Обложка и позиция | MP3 играл на 14,37 с, нажатие остановило на 14,39 с, повторное продолжило с той же позиции. Нажатие на текущую строку мини-очереди также поставило на паузу. |
| Прыжок по очереди | Из первой записи выбран четвёртый трек, который начал играть в медиатеке. Пропущенные записи остались в очереди. Выбор видео в очереди оставил медиатеку открытой и показал «Смотреть». В полной очереди выбор четвёртого трека также сработал. |
| Видео и звук | «Смотреть» открыло видео в плеере. «Слушать» запустило звук MP4 в медиатеке. При возврате от звука к видео позиция сохранилась. Подсказка для видео без звука видна при клавиатурном фокусе. |
| Вход и личная медиатека | После загрузки новой сборки в аккаунте andrey отображались 212 записей. Вкладка оставлена в режиме карточек. |

Независимое ревью выявило перезапуск текущей строки очереди, отсутствие видимой
при фокусе причины недоступности звука, нехватку места для названий узких
карточек тегов и отсутствие подписей у мобильных ссылок. Исправления приняты.
Переход по тегу также возвращает к началу выдачи.

Скриншоты в локальном `storage/verification/06-library-navigation/`: карточки,
список на 837 px, поиск по тегам, компактная очередь и мобильный каталог тегов.

## Что посмотреть руками

В медиатеке выбрать тег, уточнить запрос названием и запустить трек с обложки.
Повторно нажать обложку и открыть очередь в нижней панели. Для проверки перехода
нажать на любую доступную запись дальше по очереди.

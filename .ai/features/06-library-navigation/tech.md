# Техника

- **T01.** `PlayerProvider` добавляет вход `activateItem` для выбора записи.
  Запуск коллекции через `start` сохраняет своё назначение. Для той же записи
  используется существующее состояние плеера, смена режима использует позицию
  текущего источника. Компактная и большая очереди используют один переход.
- **T02.** `LibrarySearchControls` показывает часто используемые теги,
  поиск по доступным тегам и выбранные фильтры. Счётчики вычисляются по
  коллекции, критерии поиска продолжают храниться для аккаунта. Теги используют
  существующую комбинацию по всем выбранным значениям.
- **T03.** `ItemTable` использует интерактивную обложку и явные области сетки.
  Теги находятся в блоке записи в обоих видах, лишние раскрываются. У кнопок
  видео, меню и чекбоксов независимые зоны. `TagsPage` ведёт в фильтрованную
  медиатеку, соседние экраны используют тот же подход к заголовкам и навигации.

Серверный контракт, хранилище и миграции для этих изменений не требуются.
Обновить [карту сайта](../../map/web.md). Живую приёмку провести во встроенном
браузере, используя изолированную библиотеку и реальные локальные файлы.

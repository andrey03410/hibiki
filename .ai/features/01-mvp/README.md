# 01. Первая итерация Hibiki

Личная медиатека с источниками YouTube и локальными файлами, динамическими
составными плейлистами, ПК-плеером и полноценным управлением через MCP.

## Статус

Бриф сохранён. [Продукт](product.md) и [техника](tech.md) — предложения для
обсуждения, не подтверждённая реализация. Подтверждённые ответы владельца
отмечены отдельно. Название Hibiki и ориентация на ПК подтверждены.

Владелец разрешил сейчас только основу репозитория и слой знаний.
**До отдельного сигнала не создавать код, приложения, зависимости, БД или план
с автоматическим переходом в реализацию.** Автономный режим не разрешён.

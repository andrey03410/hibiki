# Технические решения

## Навигация и изображения

Название и обложка — две самостоятельные ссылки. Обложка передаёт состояние редактора через `?edit=1`. Выдача общей ссылки использует существующий диалог. Аудиоплеер запускается из медиатеки либо отдельной кнопкой воспроизведения.

Для крупной картинки добавлен вариант WebP до 640 пикселей, защищённый существующей авторизацией на обложки. Компактная версия остаётся 96 пикселей. Для YouTube выбирается sddefault с переходом на hqdefault при отсутствии. Обзор преобразует сохранённые адреса прежних карточек без массового пересчёта.

## Открытие плейлиста и формы

Отдельный запрос страницы возвращает метаданные и состав, использует общую семантику правил и загружает полные DTO совпавших записей. Ручные, простые избранные и подходящие фильтры ограничивают кандидатов уже в SQLite. Учитываются ручная сортировка, приватная история, вложения, исключённые записи и актуальные права. Первая отрисовка получает 24 строки и полный порядок ID. Дальнейшие страницы приходят при прокрутке после проверки актуальности, подробности исключений загружаются при раскрытии.

Форма создания из выбранного открывается с известными ID. Пользователь может сразу ввести название и сохранить плейлист. По запросу расширенного редактирования подгружается каталог для правил. Список выбора отрисовывается порциями. Сведения о проверках и измерениях — в [приёмке](verify.md).

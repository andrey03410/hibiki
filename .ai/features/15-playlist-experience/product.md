# Продуктовые решения

- На карточке собственного плейлиста название открывает подборку. Видимая текстовая кнопка «Поделиться» открывает обычный диалог ссылки, обложка открывает редактор. Быстрый запуск с обложки остаётся у треков в медиатеке. В составе подборки запуск трека доступен отдельной кнопкой.
- В каталоге и в крупной карточке медиа получатель видит чёткую обложку. Для обычных строк треков остаются компактные миниатюры.
- При входе в плейлист пользователь быстро видит название и состав. При создании из выделения немедленно получает форму, в которой можно печатать. Состав и порядок выделения сохраняются.
- Производительность улучшаем при исходном качестве звука. Решения приняты в рамках автономного поручения.

# Техника

Сейчас мини-плеер в `apps/web/src/player.tsx` показывает декоративный прогресс
и ссылку на `/player`. Большой плеер уже использует range input и общие обработчики
seek, pending position и истории. Таблица и карточки используют общие команды запуска.

- **T01.** Перенести range input и обработку начала/конца жеста в общий компонент
  `PlaybackSeekBar`. Использовать его в обеих панелях, позицию менять через
  существующий `seekFromSlider`. Верхняя полоса мини-плеера получает увеличенную
  зону нажатия и видимый ползунок.
- **T02.** Компонент `CompactPlaybackQueue` получает общий снимок очереди,
  текущий индекс и карту записей. Просмотр управляет собственным видимым состоянием.
  Кнопка связывается с панелью через `aria-expanded` и `aria-controls`, Esc возвращает
  фокус, клик снаружи закрывает окно. При смене маршрута компонент сбрасывается.
- **T03.** `LibraryPlaybackButton` получает подпись, значок и действие.
  Вид карточек скрывает визуальный текст кнопки и показывает подсказку на hover/focus.
  Использовать существующие причины недоступности и команды старта.

Решения приняты в автономном режиме. Меняется карточка [сайт и плеер](../../map/web.md).
Живая проверка во встроенном браузере на изолированной установке.

# Проверка 03: личная медиатека Hibiki

18 ноября 2026. Изолированный стенд Chromium + сервер и отдельный worker на
`localhost:8796`. Временные аккаунты, SQLite и доказательства — в
`storage/verification/03-library-workspace/` вне Git. Рабочую медиатеку не меняли.

## Живая приёмка

| Сценарий | Наблюдение |
|---|---|
| Очередь | Под реальным WAV двигали записи мышью и кнопками, удаляли и отменяли, переключали перемешивание, сохранили снимок. URL активного медиа не менялся, позиция росла. После reload те же три позиции; снимок — отдельный ручной плейлист. |
| История и правила | Настоящие WAV 12 с и MP4 7 с; короткий трек дослушан, перемотка к концу видео — частичное прослушивание с одной перемоткой. У запуска короткого трека есть ID плейлиста; на уже открытой странице «Ещё не слушал» трек исчез после старта. CSV содержит попытку. |
| Объём истории | Фикстура 1,2 ГБ **логической оценки**, без выделения 1,2 ГБ на диске. Браузер показал предупреждение, контекст для агента, отфильтрованный CSV и превью. До подтверждения обе попытки были на месте. После удалена только выбранная, сводка сохранила два запуска. |
| Замена | Настоящий MCP предложил кандидатов; чужой аккаунт получил отказ. После подтверждения реальной метаинформации YouTube появился предпочтительный Source, затем проверен локальный WAV. Браузер увидел превью и воспроизвёл файл; Item сохранил ID. Отдача файла: Range 206, 1024 байта. |
| Синхронизация | Реальный полный YouTube-снимок из 136 позиций. В изолированной БД подготовлен отличный предыдущий снимок: внешний плейлист не изменяли. Worker реально перечитал источник и применил отчёт +1/−1/2 перемещения, сохранил локальную добавку и скрытие, отметил новый item тегом. Ушедший item остался, очередь та же. Review-mode уведомил без применения; ручной режим проверен отдельно. Источник со скрытыми позициями отклонён как неполный. |
| IFrame | Официальный пример YouTube декодировался, readyState 4, позиция росла. Запуск попал в историю; позиция пережила reload без автозапуска и второй попытки. Другой ролик вернул код 150 (встраивание запрещено); проверка метаданных не приравнивается к разрешению воспроизведения. |
| Поиск и заметки | Личная заметка из карточки найдена вместе с фильтрами длительности, источника и даты. У другого аккаунта и по Bearer текста нет. ZIP перенёс заметку и сводку (без сырого журнала) между тестовыми аккаунтами. MCP не видит задачу, не скачивает файл и не выполняет произвольный запрос по истории; читает сохранённый владельцем плейлист. |
| Миграция | На копии существующей БД до/после сохранились 244 items, 247 sources, 12 playlists и 247 ItemTag. Проверка внешних ключей без строк ошибок. |
| Регрессии ревью | На 2× реальный 12-секундный WAV дослушан примерно за 6 с, без ложной перемотки. При восстановлении с исчезнувшим файлом выбрана следующая запись без автовоспроизведения и ложной попытки. Повторное создание одной связи с YouTube через другой URL вернуло тот же ID. |

## Ревью и финальный QG

Первое независимое ревью нашло косвенный доступ MCP к счётчикам через
произвольные правила и несколько пограничных сценариев. Новые проверки охватывают
закрытый доступ к правилам через Bearer и архивы, сохранение финала активной попытки
при выборочной очистке, удалённый контекст плейлиста, скорость воспроизведения,
повторную привязку URL, восстановление без автозапуска и удаление текущего трека.
Повторное независимое ревью подтвердило закрытие серверных и плеерных P1/P2.
На финальном коде также пройдены реальные браузерные сценарии очереди, скорости,
восстановления и IFrame; вызовы MCP повторены на настоящем HTTP-сервере.

зависит от доставки keepalive; уже сохранённая попытка из журнала не исчезает.

## Что посмотреть руками

- В медиатеке нажать «Действия с … → Играть следующей», переставить
  следующую запись и сохранить очередь новым плейлистом.
- В «Настройки → История и данные» посмотреть попытки после прослушивания,
  выгрузить CSV; в редакторе плейлистов добавить условие «Ещё не слушал».
- В деталях записи открыть замену, проверить кандидата; подтверждать только
  если подходит. Личный текст записывается в блоке «Заметка».
- Импортировать полный YouTube-плейлист связанным; режим можно поменять
  в «Настройки → YouTube-плейлисты». Состав и отчёт видны на его странице.

# MCP

## Текущее состояние

Сервера, инструментов и токенов пока нет. Образец — Asobiba
`apps/server/src/mcp/routes.ts`. Предложение — T08 [техники](../features/01-mvp/tech.md).

## Предложено

Streamable HTTP в сервере приложения, личный отзываемый токен пользователя.
Внешний агент узнаёт схемы, теги и доступные операции; импортирует single/playlist,
пакетно меняет метаданные, собирает/проверяет/объясняет плейлисты, управляет
заданиями и переносом. Пагинация и компактные структурированные отчёты обязательны.
Долгая работа возвращает jobId. Файлы передаются потоком через upload URL.
Общие сервисы заново проверяют владельца, включая все ссылки внутри правил.
Конкретные имена и schemas инструментов ещё не определены.

## Как проверить после реализации

Настоящий MCP-клиент проходит initialize → capabilities → import → job status →
tags → playlist validate/preview/explain/save → export/import.
Отдельно отозванный токен, чужие ID, повтор команды и большой плейлист.

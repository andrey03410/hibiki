# Окружение и проверки

## Код и команды

TypeScript-монорепозиторий npm workspaces: `apps/server`, `apps/worker`,
`apps/web`, `packages/contracts`, `packages/core`. Требуется Node.js от 22.16;
точные версии зависимостей закреплены в `package-lock.json`. Используются
Fastify 5, Prisma 7/SQLite, React 19/Vite, Zod 4 и Vitest.

| Команда из корня | Поведение |
|---|---|
| `npm ci` | Установка; `postinstall` генерирует Prisma Client |
| `npm run db:deploy` | Применение миграций через `scripts/prisma.mjs` |
| `npm run db:migrate -- --name example` | Миграция разработки и генерация клиента |
| `npm run db:generate` | Генерация Prisma Client |
| `npm run dev` | Миграции, watch-сервер, worker, Vite |
| `npm run build` | Сборка сайта в `apps/web/dist` |
| `npm start` | Миграции, сервер со статикой собранного сайта и worker |
| `npm run account -- login` | Создание аккаунта; пароль в `storage/accounts/login.json`, режим `0600` |
| `npm test` | Все Vitest-тесты |
| `npx tsc --noEmit` | Проверка типов всего репозитория |

`account` выводит только расположение файла с реквизитами; пароль в консоль не
печатается. Повтор команды для существующего логина не меняет его пароль.

## Порты, окружение и storage

Сервер по умолчанию слушает `127.0.0.1:8790`. Vite слушает `127.0.0.1:5174`
со `strictPort` и проксирует `/api`, `/files`, `/mcp` на `8790`.
Перед запуском проверь занятость портов; соседние проекты не останавливай.

Базовые переменные описаны в `.env.example`: `PORT`, `HOST`, `PUBLIC_URL`,
`STORAGE_DIR` и необязательный абсолютный `DATABASE_URL=file:…`.
По умолчанию БД — `storage/hibiki.db`. `LOCAL_MEDIA_DIRS` задаёт разрешённые
каталоги локального импорта; разделитель — системный, на macOS `:`.
Переменные yt-dlp — в [youtube](youtube.md).

`.env`, `storage/`, БД, пользовательские медиа, временные файлы, реквизиты
аккаунтов и доказательства исключены из git. В storage используются `media/`,
`uploads/`, `tmp/playback/`, `jobs/`, `imported/` и `accounts/`.
Публичные документы не содержат личные пути, адреса прокси и токены.

## Грабли SQLite

`scripts/prisma.mjs` загружает `.env`, создаёт родительский каталог и при
необходимости пустой файл SQLite через режим `ax`: Prisma 7 на macOS требует
существующий файл. Существующая БД не обнуляется. Не заменяй wrapper прямым
`prisma migrate deploy`, не проверив первый запуск на macOS.

`db.ts` включает WAL, foreign keys и busy timeout 5 с. `sqlite.ts` сериализует
запросы общей Prisma-связи с транзакциями и хранит DateTime как ISO-строки.
Внутри `$transaction(async tx => …)` обращайся только через `tx`: запрос к
корневому клиенту будет ждать завершения этой же транзакции. Отдельно обработан
ROLLBACK после неуспешного COMMIT, чтобы следующие записи не остались внутри него.

## Как проверить

После последних правок кода обязательный порядок:
`npm test` → `npm run build` → `npx tsc --noEmit`. Затем живые поверхности
по [verify](../../.claude/skills/verify/SKILL.md): настоящий браузер, MCP,
декодирование/seek медиа, задания и перенос под другим аккаунтом.
Для правок только документации достаточно проверки ссылок и путей.

Тесты создают отдельные временные БД; реальные YouTube-сценарии и свёрнутое окно
не заменяются тестовыми провайдерами. Ограничения и фактические результаты
записываются в `verify.md` задачи.

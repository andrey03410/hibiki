# Окружение и проверки

## Текущее состояние

Приложение, `package.json`, lockfile, зависимости и CI ещё не созданы.
Команд dev/start/test/build/typecheck и схемы БД нет. Не запускать их до реализации.
В основе репозитория есть README, AGENTS, gitignore, editorconfig, скиллы и документы.

## Предложено для реализации

Node.js LTS, npm workspaces; Fastify и Vite в разработке, сервер и worker
в рабочем запуске. Кандидаты портов — 8790 и 5174, без конфликта с Asobiba/Douga.
Перед запуском проверить порты; не останавливать соседние проекты.
Конкретные версии, команды, переменные, миграции и путь БД записать после создания.
Файлы пользователя, БД, временные задания и доказательства — в `storage/` вне git.

## Как проверить

Сейчас: ссылки, симлинки CLAUDE.md и .agents/skills, frontmatter скиллов,
исключение секретов/storage, отсутствие кода и зависимостей.
После появления кода: `npm test` → `npm run build` → `npx tsc --noEmit`, затем
поверхности по [verify](../../.claude/skills/verify/SKILL.md).

См. [технику](../features/01-mvp/tech.md), T01/T02/T10.

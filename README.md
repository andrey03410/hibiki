# Hibiki · 響き

Личная медиатека с гибкими составными плейлистами и управлением через ИИ-агентов.
Название Hibiki означает «звучание, отзвук».

Публичный репозиторий: [andrey03410/hibiki](https://github.com/andrey03410/hibiki).

Пользователь собирает собственный пул аудио и видео: загружает файлы или добавляет
ссылки YouTube, в том числе целые плейлисты. Теги, ручной выбор и другие плейлисты
становятся источниками новых динамических подборок. Сайт и MCP используют общие
правила и работают от имени пользователя.

## Состояние

**Только основа репозитория и слой знаний. Приложение ещё не реализовано.**

На 17 ноября 2026 года сохранены исходный бриф, границы первой итерации,
предлагаемые продуктовые и технические решения, карты зон и скиллы рабочего
процесса из Asobiba/Douga, адаптированные под Hibiki.

Владелец попросил начать реализацию только после отдельного сигнала.
Автономный режим не разрешён. Обсуждение и уточнение документов допустимы сейчас.

## Первая итерация

- Локальные аккаунты и отдельная медиатека каждого пользователя.
- Загрузка аудио/видео, добавление YouTube-ссылок и импорт состава YouTube-плейлиста.
- Сохранение названий и items при недоступности внешнего источника.
- Скачивание через yt-dlp в локальный источник того же item.
- Предустановленные и свои теги, ручные и составные динамические плейлисты.
- ПК-плеер с очередью, перемешиванием, повтором и сохранением состояния.
- MCP для основных операций, массовые команды и фоновые задания.
- Экспорт и импорт библиотеки с настройками, ссылками и локальными файлами.

Телефон не входит в MVP. Продолжение воспроизведения при свёрнутом браузере
проверяется для локальных файлов; ограничения YouTube описываются отдельно и
не блокируют выпуск MVP. Детали: [продукт](.ai/features/01-mvp/product.md).

## Предлагаемый стек

TypeScript · Node.js LTS · npm workspaces · React + Vite + React Router · Fastify ·
SQLite + Prisma 7 · Zod 4 · MCP Streamable HTTP · yt-dlp · FFmpeg/FFprobe · Vitest.
Долгие операции выполняет отдельный worker с очередью в SQLite.

Это техническая рекомендация для первой реализации. Зависимости, схема БД,
`package.json`, приложения, команды запуска и CI появятся после сигнала владельца.
